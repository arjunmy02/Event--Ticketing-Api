# Event Ticketing System

## Project Overview
A full-stack Event Ticketing System built using HTML, CSS, JavaScript, Spring Boot, and PostgreSQL. The application allows users to browse events and book tickets through a REST API.

## Features
- View available events
- Book event tickets
- RESTful APIs
- PostgreSQL database integration
- Responsive frontend

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Maven

### Database
- PostgreSQL
